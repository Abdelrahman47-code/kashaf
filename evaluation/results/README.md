# Submissions go here

`python -m kashaf.run` writes `Kashaf.csv` here; `python evaluation/run_evaluation.py` scores
whatever `*.csv` is in this folder against the public 5-minute ground truth. The contents of
this directory (except this README) are gitignored: a submission is a full set of labels for
the match and must never be committed to a public repository. Upload the CSV through the
competition form instead.
